# Herit Estate Service

Herit is a static front-end prototype for inheritance real estate trust planning.

## Features

- User-facing estate planning landing page
- Inheritance tax quick estimator
- Trust suitability assessment
- Family asset portfolio board
- Trust vault progress view

## Run Locally

```bash
npm start
```

Then open `http://127.0.0.1:5173`.

No external dependencies are required for the static server script.
